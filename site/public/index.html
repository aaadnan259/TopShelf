Amazon search, sorted by what buyers actually think.

A 5-star listing with 14 reviews shouldn't outrank a 4.8 with 24,000. TopShelf re-sorts the results page you're already looking at, using only what's on it. Nothing leaves your browser.

The one rule it's tuned around: burying a good product is worse than letting a mediocre one rank a little high. So TopShelf demotes on soft signals and only hides what's clearly below the rest of the page.

    How it ranks.

    1. It reads what's already on the page. Rating, number of ratings, price, and the Sponsored label for each result. Nothing is fetched; the extension's only permission besides Amazon search pages is storage for your settings.
    2. It discounts ratings that haven't been earned yet. Each rating is blended with the page's average as if it had 50 extra average ratings: (50 × page average + rating × count) ÷ (50 + count). A 5.0 with 14 ratings lands near the average. A 4.8 with 24,000 stays 4.8.
    3. It demotes, rather than hides, on soft signals. Sponsored listings lose 15%. A rating of 4.8 or higher on fewer than 100 ratings loses 20%, since that's what review farming looks like, but that alone never hides anything.
    4. It hides only what's clearly worse. On the default Standard setting, a listing is hidden if its weighted rating is more than 0.6 stars below the page average. Aggressive uses 0.3; Off hides nothing on rating.
    5. It moves Amazon's own tiles. Links and cart buttons work as before, the top three get a badge that explains itself when clicked, and a chip in the corner switches back to Amazon's order or shows what was hidden.

    Value mode divides the score by log10(price + 10), so cheaper listings move up without a $9 one automatically winning. The full spec is in CLAUDE.md.

    Questions.

    Does TopShelf send my browsing data anywhere?
    No. There's no server and no analytics, and the code has no fetch or XMLHttpRequest anywhere. Its permissions are Amazon search pages and Chrome storage for your settings. You can watch the Network tab to check.
    Does it hide products?
    Some, by default. On the Standard setting, listings whose weighted rating is more than 0.6 stars below the page average are hidden, and the chip in the bottom-right shows a "Show N hidden" button to bring them back. Set the floor to Off in the options page and nothing is hidden on rating. Sponsored listings are demoted by default; you can hide them or leave them alone instead. Nothing is ever removed from the page, only moved or hidden.
    Why not just sort by rating?
    Because a 5.0 from 14 people tells you much less than a 4.8 from 24,000. TopShelf treats every listing as if it also had 50 ratings at the page's average, which barely moves well-reviewed products and pulls thinly reviewed ones toward the middle until they've earned their spot.
    Does it work with Knockoff?
    Yes, if you have it. When Knockoff marks a listing, TopShelf gives a known brand a 5% boost, demotes a suspect one by 40%, and hides a flagged one. Without Knockoff installed, nothing changes.
    Which browsers does it run in?
    Chrome, and Chromium browsers that load Chrome extensions, such as Edge and Brave. It isn't on the Chrome Web Store yet, so for now you load it unpacked from the repo; the install steps take a minute.
