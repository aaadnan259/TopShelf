# Release notes

## v0.1.0 — first release
- Re-ranks Amazon search results best-first with a confidence-weighted
  (Bayesian) rating.
- Quality and Value ranking modes.
- Review-farm demotion (high rating, few reviews) — demote-only, never hide.
- Sponsored listings demoted by default; option to hide or leave alone.
- Explainable rank badges on the top 3 listings.
- Hidden-tile floor (Off / Standard / Aggressive) with one-click reveal.
- Instant toggle back to Amazon's original order.
- Zero network requests. Settings in Chrome sync storage only.
